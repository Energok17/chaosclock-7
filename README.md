# ChaosClock 4.1.0

Minecraft **Forge 1.20.1** мод.

Рандомні хаос-івенти по таймеру на кожного гравця + **система карми** + зілля удачі + магазин виклику івентів.

## Features

### Karma
- Діапазон: **-500 … +500** (старт з 0)
- Вбивство ворожого моба → **+2…+5** карми
- Вбивство мирного моба → **-1**
- Смерть гравця → **-10**

### Вплив карми на івенти
| Карма     | Доступні івенти               |
|-----------|-------------------------------|
| ≥ +400    | EPIC + LEGENDARY + DIVINE     |
| ≥ +100    | RARE і вище                   |
| -99…+99   | Усі івенти                    |
| ≤ -100    | Усе, крім DIVINE              |
| ≤ -400    | тільки COMMON → EPIC          |

### Команди
- `/karma` — показати карму
- `/karma set <value>` — встановити (op)
- `/karma shop` / `/karmashop` — прайс
- `/force rare|epic|legendary|divine` — викликати івент за карму
- `/chaosclock interval <seconds>` — змінити інтервал (op)

**Ціни force:**
- rare — 25
- epic — 50
- legendary — 100
- divine — 200

### Зілля
- **Surge of Fortune** — 10 хв, RARE+
- **Pure Surge of Fortune** — крафт з 9 звичайних, 2 хв, **EPIC+**

## Збірка

```bash
./gradlew build
```

Готовий JAR буде в `build/libs/chaosclock-4.1.0.jar`

## Примітка
Частина класів (особливо `ChaosEvents`) після декомпіляції може містити intermediary-імена.  
При першій збірці можливі помилки компіляції — потрібно буде почистити імена під official mappings.
